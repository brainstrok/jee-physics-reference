# Mechanics Formula Sheet

## Units and Dimensions

- SI units of length = m
- Mass = kg
- Time = s
- Force = N = kg m s^-2
- Work/energy = J = N m
- Power = W = J s^-1

## Vectors

- Dot product: a · b = ab cos θ
- Cross product: |a × b| = ab sin θ
- Resultant of two vectors: R = √(A² + B² + 2AB cos θ)

## Kinematics

- v = u + at
- s = ut + (1/2)at²
- v² = u² + 2as
- average velocity = total displacement / total time

## Newton's Laws

- F = ma
- Friction: f ≤ μN
- Static friction: adjusts up to maximum value
- Kinetic friction: f_k = μ_k N

## Work, Energy, Power

- W = F·s = Fs cos θ
- K.E. = (1/2)mv²
- P.E. = mgh
- Power = W/t = F·v
- Work-energy theorem: W_net = ΔK

## Circular Motion

- Centripetal acceleration: a_c = v²/r
- Angular speed: ω = v/r
- Centripetal force: F_c = mv²/r

## Center of Mass

- x_cm = Σm_i x_i / Σm_i
- y_cm = Σm_i y_i / Σm_i

## Rotation

- τ = r × F
- τ = Iα
- K.E. rotation = (1/2)Iω²
- Angular momentum: L = Iω

## Gravitation

- F = Gm₁m₂/r²
- g = GM/R²
- Escape velocity: v_e = √(2GM/R)

## Properties of Matter

- Stress = F/A
- Strain = change in length / original length
- Young's modulus: Y = stress/strain

## Key note

For every formula, always remember:
- assumptions
- direction
- sign convention
- units
- limiting case
